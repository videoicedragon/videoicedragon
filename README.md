# videoicedragon

A Python desktop application project built with Qt.

## About

videoicedragon is planned as a desktop application developed using Python and a Qt framework. The project focuses on creating a cross-platform graphical user interface with native-feeling widgets and an organized application structure.

## Technologies

- **Python** — application logic and scripting
- **Qt** — desktop graphical user interface framework
- **PySide6** — recommended Python bindings for Qt 6

## Goals

- Build a responsive desktop interface
- Support desktop platforms such as Windows, macOS, and Linux
- Keep application logic separate from the user interface
- Use Qt widgets and layouts for a maintainable interface
